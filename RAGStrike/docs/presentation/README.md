## The one thing to get right

**Do not claim RAGStrike has found real vulnerabilities.** It has not — the full differential run has
not been completed, and every document in this repository says so.

Present what is true: a complete framework, a hardened reference target to check it against, and a
validation suite whose results are honestly reported as incomplete. That is a stronger position than
an unverifiable claim, and it survives the follow-up question.
